# E19 — No-cue text-stream adaptation pilot (locked before outcome run, 2026-10-05)

## Scope
This tests a *small linear text classifier* on genuine news text. It is NOT an LLM, trained EBM, FiUni implementation, or self-evolution. E18 showed fixed input-only detectors cannot identify a label-only rule change; this pilot tests whether observed error feedback times an adapter better than simpler controls when a visible domain shift is present. A win here licenses a more serious language-model experiment, not a claim of competitive LLM performance. Historical E0–E18 results are immutable.

## Data / independence
- SetFit/ag_news (`https://huggingface.co/datasets/SetFit/ag_news`, pinned revision `ca5ba619eb034211db5f70932b6702efd21e7c73`), `train.jsonl` SHA-256 `ea432c816ef5219d8bd1e049d63f5e05ad76b35e5efd15420d48a96f15ddaa94` (120,000 rows) and `test.jsonl` SHA-256 `68290dee715edcb5a28ff1f3fc933ea7649fb0f01263af94411cfec255c55284` (7,600 rows). Retrieval paths/command in report; do not commit raw corpus. Four source categories: World 0, Sports 1, Business 2, Sci/Tech 3.
- Pre-run integrity discovery: the published corpus has **10** train rows repeating official-test text and **151** repeated train texts (lowercase + collapsed whitespace). Before ANY seed selection, drop train rows whose normalized text occurs in official test and keep only the first occurrence of each remaining normalized train text; log actual removal counts, assert zero split/test overlap. This collision-removal rule was added **before E19 outcome execution** after a corpus-only scan; the prior protocol commit remains visible.
- Seeds: 31, 37, 41, 43, 47. Per seed, shuffle the cleaned official training set independently within each class; use first 800/class for training, next 200/class for validation, and official test for FINAL reporting. Verify no normalized-text duplicates across selected train/validation/test (fail closed). Stage A: World→0, Sports→1; Stage B: Business→0, Sci/Tech→1. No explicit task identifier in model input. Topic is an implicit signal, not an invisible shift; test accuracy must be measured on both domains without supplying the phase label.
- HashingVectorizer, 2^12 dimensions, word 1–2 grams, non-negative counts, L2 norm, fixed transformation without vocabulary fitting. Base: logistic linear 4096→2, 120 Adam steps, batch 64, LR .02 on A. Record A train/val/test. B adaptation pool: first 256 examples/class shuffled together (512 total) from B training; first 32 form monitor/router support, subsequent samples feed adaptation. No A examples during primary adaptation. All adaptation arms get 100 Adam steps, batch 64, LR .02, on 384 examples immediately following their trigger (if too few remain, redesign before looking at outcome; log such a failure). Fixed per-seed minibatch draws reused across arms.

## Arms and trigger
Frozen base; naive full fine-tune of all weights; scheduled zero-init linear residual adapter at B block 1; random trigger in B block {1,2,3} using seed-specific RNG; feedback trigger when 32-example B block error count exceeds *maximum* old-validation block error count (calibration from A only). Assess a fixed density-only alarm separately: cosine-distance to A centroid, calibrated to 95th percentile of old validation; not used as a task oracle. An adapter is physically created at trigger, and only that adapter trains. Input-only routing at evaluation: choose B adapter when cosine similarity to its 32-example trigger support centroid exceeds similarity to the A-train centroid; do not use labels/test-domain identity at evaluation. For the full fine-tune comparator, no router is used. Report identical-input/function-preservation before thawing, trigger delay and false alarms, and test old/new accuracy. If trigger never occurs, score feedback as frozen, not retrospectively force expansion. Scheduled and random use the same unsupervised router construction and training budget as feedback.

## Gates (fixed before running)
1. Base A test accuracy >=80%; if not, instrument invalid, report as such.
2. Feedback adapter B test accuracy >=65%, old retention drop <=5 percentage points; feedback balanced (old+new)/2 >= scheduled AND random by at least 2 percentage points on average across five seeds, and advantage positive in >=4/5 paired seeds. This is a *strict* timing win; an equal result is a failure of the timing claim even if adapter beats full fine-tune.
3. Report all arms per seed, arithmetic mean and std, trainable and total parameters, measured adaptation seconds, feedback delay, test count. Compare same-class linear TF-IDF/logistic controls; NEVER compare this score to general LLM leaderboards. Explicitly mark unequal end-to-end compute/latency and any violated prerequisite.

## Leakage and claims
No test score is consulted for thresholds or hyperparameter choice. Old validation alone calibrates feedback/density. Old and new class/domain identities are used to assemble training/evaluation splits, *not to route at inference*. Small dataset, phase boundary intentionally externally known to scheduled control (strong comparator); feedback sees only prediction errors. Selection of this benchmark and hyperparameters is exploratory based on earlier E16–E18; the locked E19 run itself is confirmatory only for this narrow protocol. Frozen pretrained embeddings, EBM descent, self-play, ternary kernels, full LLM and freeze/swap remain untested. Closest original studies are noted in `PRIOR_ART_E18.md` (FiUni, SEMA, density-guided routing) and must not be represented as reproduced by these deliberately weaker controls.
