**Decision against locked gates:** A baseline passes the ≥80% prerequisite. Feedback always fired after exactly 32 observed labels, the same first-block point as scheduled; therefore its output equals the scheduled arm on every seed (**0.00-point timing advantage**, vs required ≥2), and the new-task accuracy is **59.15%**, below ≥65%. Feedback beats matched random by only **0.55 balanced points**, not ≥2. The strict causal-timing gate **fails**. Full fine-tune has a **3.98-point** better balanced mean than feedback, while dropping the old skill by **5.84 points** versus **0.19**. Do not label this a win or a competitive model.

**Diagnosis (from held-out measurements, exploratory after outcome):** the fixed nearest-centroid route sends only **19–28%** of new-domain test articles to the new adapter, yet routes **2–8%** of old-domain articles there. Input-density calibration rarely flags the first B block (0–12.5% individual-article alarm rate at a 5% old-validation cutoff). The adapter has 8,192 trainable weights; the full single-head model has 8,194, but the routed adapter's total inference weights are 16,386. Equal optimizer steps/batch sizes do not establish equal end-to-end compute, including data, detector, routing, and base training. Adapt wall time on this tiny head is not evidence of a faster language model.

**Limitations:** This is actual English news text but a *small hashing-feature linear classifier*, not text generation, a pretrained LLM, learned energy, FiUni, or a faithful density-routing research implementation. It changes both topic distribution and label semantics; the phase is invisible to the input interface, but topic itself is an implicit clue. Scheduled knows the phase boundary, intentionally a strong control. The balanced binary categories are not the standard four-way AG News benchmark; do not compare these percentages to published 4-class leaderboard scores. The raw record's dirty-tree flag reflects the untracked `research-site/` build folder created by the repository's own site test, not an uncommitted modification to the pinned runner/protocol. Source hashes and Git base are recorded.

**Next experiment, not retroactive tuning:** E20 should improve the route using an independently trained/calibrated two-domain classifier on *training/validation only* (and compare simple replay/joint classifier, fixed equal-parameter adapter, density and error triggers). Seal a *different test dataset or new held-out split* after the E19 test has already been seen. If adapter improves only with externally provided task identity or larger inference capacity, name that tradeoff; do not credit timing. A real language-model round with source-controlled tokenizer and generation evaluation is required before describing the system as competitive with LLMs. Relevant earlier prior-art pointers and exact original publication links are in `PRIOR_ART_E18.md` (SEMA, FiUni, UAI density routing); these are *not implemented baselines* here.
